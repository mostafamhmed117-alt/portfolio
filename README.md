# Portfolio

A React + Vite portfolio site, ready to deploy on Vercel.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Push this folder to a Git repo and import it in Vercel, or run:

```bash
npx vercel
```

Vercel auto-detects Vite projects (build command `npm run build`, output directory `dist`).
